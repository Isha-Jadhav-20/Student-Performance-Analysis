# Student Performance Analysis

## Project Description

This project analyzes student academic performance using Python, Pandas, MySQL and Data Visualization.

## Technologies Used

-> Python
-> Pandas
-> NumPy
-> Matplotlib
-> Seaborn
-> MySQL
-> ReportLab

## Project Features

-> Data Cleaning
-> Statistical Analysis
-> Student Performance Analysis
-> Data Visualization
-> Business Insights
-> Automatic PDF Report Generation

## Project Structure

Student_Performance_Analysis
│
├── data
├── src
├── charts
├── reports
├── sql
├── main.py
└── README.md

## How to Run

Install required libraries:
    -> pip install -r requirements.txt
    -> Run the project:
    -> python main.py

## Output

The project automatically generates:

-> Cleaned Dataset
-> Statistical Summary
-> Business Insights
-> Charts
-> PDF Report
